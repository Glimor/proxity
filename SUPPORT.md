# Support

Start with the [user guide](docs/user-guide.md) and [developer guide](docs/dev.md).
Use [Discussions](https://github.com/Glimor/proxity/discussions) for setup questions,
ideas, and general help. Use the issue forms for reproducible bugs and focused
feature or documentation requests.

Include the Proxity version, Windows build, steps tried, and sanitized logs when
relevant. Remove passwords, proxy credentials, private endpoints, usernames, and
personal paths. Do not upload a live proxy export.

Report vulnerabilities using [private vulnerability reporting](https://github.com/Glimor/proxity/security/advisories/new),
following [SECURITY.md](SECURITY.md). Support is provided by volunteers; response
times and fixes are not guaranteed.
